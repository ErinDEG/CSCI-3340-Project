# Campus Hub user stories

## Story 1. Use the home page

As a student, I want to see what I can do on Campus Hub so I know where to start.

**Acceptance criteria**

* As a guest, I can sign up, log in, or choose to browse events.
* When I am logged in, the home page greets me by my first name or username. I can open my profile, browse events, or add an event.
* The home page shows which features are coming next.

## Story 2. Create an account

As a new student, I want to make an account so I can use Campus Hub.

**Acceptance criteria**

* I can sign up with a username that is available and a valid password that I enter twice.
* After I sign up, I am logged in and taken to the home page.
* I see an error if my username is taken or my passwords are invalid or do not match.

## Story 3. Log in

As a returning student, I want to log in so I can view my profile and campus events.

**Acceptance criteria**

* My username and password take me to the home page when they are correct.
* If the profile, event list, or event form sends me to log in, I return to that page after logging in.
* If my username or password is wrong, I see an error and stay logged out.

## Story 4. Edit my profile

As a student, I want to update my name so Campus Hub can greet me by my first name.

**Acceptance criteria**

* My profile shows my username and lets me change my first and last names.
* I see a message when my changes are saved. My name is still there the next time I log in.
* I am asked to log in if I open my profile as a guest.

## Story 5. Log out

As a student on a shared computer, I want to log out so the next person cannot open my profile.

**Acceptance criteria**

* When I log out, I return to the guest home page.
* If I open my profile or an event page, I am asked to log in again.

## Story 6. Browse and post events

As a student, I want to browse and post events so I can see what is happening and share my own plans.

**Acceptance criteria**

* After logging in, I can see the event list and add an event with a name, location, and description.
* The event appears in the list with my username as the creator.
* If there is a problem with what I entered, the form shows which field to fix and keeps what I typed.
